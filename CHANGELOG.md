### Changed

- Renamed to gameWE: plugins `gamewe_<game>.amxx`, cvars `gamewe_*`, server commands
  `gamewe_amx_*`. The `gameme_amx_*` commands still work, and the SourceMod spelling
  `gamewe_psay`, `gamewe_msay`, ... is added, so the collector can use one command
  set for all games.
- One shared core (`gamewe_core.inc`, `gamewe_xstats.inc`) instead of five copies of
  the same code. The game plugins only hold what differs.
- Needs AMX Mod X 1.9 or newer. Settings are in `configs/plugins/gamewe.cfg`
  (`AutoExecConfig`).
- Chat behaviour as in the SourceMod plugin: `/rank` is silent (hidden, logged by the
  plugin), `!rank` and `rank` stay visible and are logged by the game.
- Colored chat on Counter-Strike uses `client_print_color` instead of the TeamInfo trick.
- `psay2` is really green on Counter-Strike now.
- Weapon names in `weaponstats` are the log names of the kill lines on all games.
- `attacked` lines carry the real damage, armor damage, health and armor.
- The menu entries send the `gamewe_*` chat commands (`/gamewe_hideranking`, ...).

### Added

- `weaponstats` lines when a player disconnects.
- `joined team` log line when the collector swaps a player.
- Cvars `gamewe_chat_cooldown` (flood protection for chat commands) and
  `gamewe_log_damage`, server command `gamewe_message_prefix_clear`.
- Makefile, `tools/build-amxxpc.sh` (builds the compiler from the pinned AMX Mod X
  sources) and a GitHub workflow that builds every commit on `main`;
  semantic-release makes the releases from Conventional Commits.
- `INSTALLATION.md` with every install step, including game servers in a container.
- Settings menu: `settings` / `gamewe_settings` in chat or `amx_gamewe_settings` in the
  console. "Hide me in the ranking" and "Show me in the ranking" send
  `/gamewe_hideranking 1|0` for the player (collector 0.1.0 or newer).
- `hideranking` and `(gamewe_|gameme_)hideranking 1|0|on|off|hide|show` are hidden chat
  commands. `settings` / `gamewe_settings` open the menu and are neither shown nor logged,
  so the collector does not answer them as well.

### Removed

- Cvar `gamewe_block_commands`: the chat behaviour is fixed (see above). An old
  `gamewe_block_commands` line in the config is ignored.
- Menu entries "Auto Ranking", "Console Events", "Reset Statistics" and
  "Toggle Ranking Display": the collector does not handle them.
  The main menu has a "Settings" entry instead.

### Fixed

- `hlmp`, `ns` and `tfc` did not compile with current compilers (array out of bounds).
- `gameme_amx_browse` opened any server file in the MOTD window when the argument was
  not a URL (`show_motd` reads files). Only `http://` and `https://` URLs are accepted now.
- Arguments are parsed from the raw command line, so messages and URLs with `:`, `(`,
  `)` or `'` are no longer cut or changed, and `msay` keeps the text after the last line break.
- `msay` ignored the display time and always used 15 seconds.
- `swap` read the team of player `-1` when the userid was unknown.
- `attacked` lines were also written for world damage (attacker 0).
- `weaponstats` could be logged twice when a player died after the round end.
- `gameme_block_commands_values` ignored a single command and stopped after ten.
- The TFC menu entries "Auto Ranking" and "Console Events" sent the wrong commands.
